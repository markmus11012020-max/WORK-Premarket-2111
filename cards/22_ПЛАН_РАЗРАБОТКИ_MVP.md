# Карточка 22. План разработки MVP

**Вопрос:** Как вы организуете разработку MVP за следующий этап?

**Лимит:** 5000 знаков.

**Объём ответа:** 1000 знаков с пробелами.

## Ответ для платформы

11 дней, 2 роли: инженер — MCP, RAG, LangGraph, ядро, UI; капитан — корпус, сценарии, промпты, демо.

23–24.11: доступ к MCP, токен, сертификаты, sandbox; скелет LangGraph; схема данных; 10–15 документов для RAG. Проверяем портфель, новости, оферты и амортизацию.

25–26.11: MCP-инструменты и портфель; детерминированное ядро (YTM/YTC, НКД, концентрация, ликвидность); карточка события; RAG-индекс и поиск с цитатами.

27–28.11: сборка графа: классификация → MCP → RAG → ядро → LLM → HITL; структурированный ответ; ветки «нет данных» и ошибок.

29–30.11: end-to-end прогон; 20–30 размеченных кейсов; Recall/F1, Recall@5, faithfulness; фиксы.

01–02.12: UI-полировка, 5–7 пользовательских тестов, демо-сценарий, фикстуры и fallback; проверка безопасности.

03.12: предпроверка, заморозка, бэкап. 05.12: демо.

Параллельно: капитан — корпус и вопросы, инженер — сборка; оба проверяют. Критичные неизвестные — MCP, оферты, эмбеддинги — проверяем в первые 2 дня; если нет, упрощаем сценарий, без выдумок.

## Пометки

- План на двух человек, без скрытой третьей роли.
- Критичные неизвестные проверяются в начале.
- 03.12 — предпроверка, 05.12 — финал.
