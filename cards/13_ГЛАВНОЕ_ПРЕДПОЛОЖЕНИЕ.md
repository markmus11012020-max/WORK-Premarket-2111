# Карточка 13. Главное предположение

**Вопрос:** Какое главное предположение вы проверяете и как?

**Лимит:** 5000 знаков.

**Объём ответа:** 927 знаков с пробелами.

## Ответ для платформы

Главное предположение: AI-агент на LangGraph с RAG способен на реальных новостях найти релевантные фрагменты, извлечь событие, связать его с портфелем и объяснить без выдумок. Если нет — продукт превращается в дашборд.

Проверка: 20–30 новостей и раскрытий, тестовый портфель 5–7 выпусков. Прогон: LangGraph → MCP → RAG → ядро → LLM. Считаем: извлечение события — Recall ≥ 0,9, F1 ≥ 0,85; поиск RAG — Recall@5 ≥ 0,9; ответ — faithfulness ≥ 0,85 (RAGAS), 0 выдуманных фактов и рекомендаций; граф завершает сценарий без падений.

Аргумент за: пороги достигнуты, HITL работает, ошибки уходят в резервный путь. Против: пороги ниже, есть выдумки, граф зацикливается или падает. Недостаточно: выборка меньше 20, разметка неполная, только один тип событий. RAGAS — офлайн-оценка, не runtime.

Что это не докажет: один удачный кейс не подтверждает надёжность на всех событиях. Нужна выборка с разметкой и проверка разных типов событий.

## Пометки

- RAGAS — инструмент оценки, не runtime.
- Пороги — критерии, а не обещание качества.
- Проверка в первые дни MVP, до пилота.
