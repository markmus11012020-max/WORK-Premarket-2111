# Карточка 09. Зачем нужен T-Invest MCP

**Вопрос:** Зачем в решении нужен T-Invest MCP?

**Лимит:** 5000 знаков.

**Объём ответа:** 903 знака с пробелами.

## Ответ для платформы

T-Invest MCP — источник данных о портфеле и рынке: портфель, позиции, котировки, стакан, новости, поиск. Он не заменяет RAG: MCP отдаёт данные, RAG индексирует новости и раскрытия и находит релевантные фрагменты по смыслу. LangGraph вызывает MCP как инструмент на шаге загрузки портфеля и новостей.

Поток: событие → LangGraph → MCP → RAG → ядро (YTM, НКД, концентрация, риск-гейт) → LLM → HITL.

Подтверждено документацией: портфель, котировки, стакан, новости, поиск, sandbox, read-only. Проверить: график оферт и амортизации, кредитные события и рейтинги, глубину новостей, лимиты. Если метода нет — резервный путь или раскрытия, без выдумок. Торговые методы не используем.

Почему MCP, а не только Open API: MCP даёт агенту стандартный доступ к инструментам, меньше кастомной интеграции и единый контур с sandbox. Open API — резерв для методов, которых не хватает. MCP не гарантирует полноту данных.

## Пометки

- «Подтверждено документацией» не равно «проверено в sandbox».
- MCP — доступ к данным; RAG — поиск по неструктурированному тексту.
- Торговые методы MCP не входят в MVP.
